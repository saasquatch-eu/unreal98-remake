# Content and licensing boundaries

Repository policy: only independently authored code, documentation, synthetic
fixtures, and assets with recorded redistribution permission belong in Git.

Keep original game packages, maps, textures, models, music, sounds, UnrealScript,
and engine source outside tracked files. Ignored `reference/local/` and
`data/local/` are available for later private work. Ignore rules are a convenience;
review files before staging, including future UE `.uasset` and `.umap` imports.

No public code license has been selected and no permission for a complete remaster
release has been verified. Those decisions remain separate from this local setup.
The UE installation is external and is not part of this repository's contents.
