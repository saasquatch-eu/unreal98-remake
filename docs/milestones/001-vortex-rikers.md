# Later gameplay milestone: Vortex Rikers (Vortex2)

The first visual target is now the castle intro, `Unreal.unr`; see
`003-unreal-intro-preparation.md`. Vortex Rikers remains the later milestone for
player movement, collision, triggers, moving objects, pickups, and progression.
Keep its original map stem `Vortex2`; a future UE5 level is `Vortex2_ue5.umap`.

Validate a representative section rather than promise a complete converted map.
No schedule is committed during setup.

1. UR-001: repository and environment setup; no feature development.
2. UR-002: create, compile, and run a native macOS UE C++ project when requested.
3. UR-003: inspect an actual original map export and establish a local export route.
4. UR-004: implement and test a parser against a representative T3D structure.
5. UR-005: verify coordinate conversion, evaluated geometry, UVs, and collision.
6. UR-006: prototype UE editor import for a representative section.
7. UR-007: measure and reconstruct original movement.
8. UR-008: demonstrate lighting/material direction without changing gameplay.

Compilation, editor launch, real export inspection, geometry validation, gameplay
comparison, and visual review require distinct recorded evidence. Setup alone does
not satisfy those acceptance criteria.
