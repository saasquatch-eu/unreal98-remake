# Source inspection contract

`t3d-inspection-v1.md` describes the implemented JSON source inventory. It records
observations from a local export, not evaluated CSG or a UE5 importer contract.
The evaluated-geometry bundle is documented separately below.

`brush-audit-v1.md` documents the checksum-bound numeric evidence and
source-coordinate audit. It also does not define an evaluated mesh format.

`evaluated-geometry-v1.md` describes the original compiled-BSP geometry bundle,
including retained boundaries, texel UVs, sky/portal roles, and separate Movers.
